# 头脑风暴 · BRAINSTORM

每天早上 08:30（北京时间），GitHub Actions 自动抓取 AI 资讯，由 AI 筛出 **10 个可落地的创意**并发布到本站：
**https://thejourneyoflaw.github.io/brainstorm-site/**

- 板块：今日脑洞 / 前沿关注（公众号更新追踪）/ 历史归档（按月）
- 管线：分池草稿 → 自检清单 + 五维评分 → 异模型终审 → 落地路线深化
- 数据源：AIHOT（aihot.news，含署名与原文链接）+ 手动收件箱

本仓库为公开展示与运行仓库；数据由 Actions 生成并自动提交。
